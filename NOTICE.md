## What is in this repository and where it came from

**Our own work, GPL-3:** everything in `src/`, `plugin/`, `hollow/`, `tools/` and `docs/` except the files listed below. The engine is a clean rewrite in C++ of what the FS1R's CPU does between MIDI and the tone generator registers, worked out by reading the v1.20 firmware. It contains no Yamaha code. `hollow/` is the plug-in framework the editor runs on, written for this project and its sibling products.

**Extracted from Yamaha's EPROM, not ours to license:**

- `src/fs1r/firmware/tables.h` - the CPU-side conversion tables (velocity curves, level scaling, the note table, the pan tables and the rest), generated by `tools/extract_tables.py` from a v1.20 EPROM image.
- `src/fs1r/firmware/algorithms.h` - the 88 algorithm words.
- `presets/` - the 1408 preset voices, the 384 preset performances and the 90 preset formant sequences, as `.syx` files and an index, generated by `tools/extract_presets.py`, and the same data packed into `plugin/generated/fs1r_presets.syx`, `fs1r_presets.csv`, `fs1r_performances.syx` and `fs1r_fseqs.syx` by `tools/make_presets_blob.py` so the plugin can load them with no EPROM image present.
- `docs/vop3_microcode.md` and `docs/vop3/` - VOP3-1's program and coefficient tables, the YSS236 that runs the per-voice filter, generated by `tools/extract_vop3.py`. Reference material; nothing here depends on it.
- `src/fs1r/firmware/vop3host/rom_tables.h` and `rom_tables.cpp` - 88,558 bytes of the v1.20 EPROM, from CPU addresses 0x35D732..0x388F18 and 0x3895F2..0x389830: the effect and filter chips' programs, constants, laws and parameter ranges that the two hosts read, as named tables, generated by `tools/extract_vop3_rom.py`. The effects and the voice filters run on them.

These are Yamaha's data. They are included because the emulation is worthless without the exact tables, and because the tools that regenerate them from an EPROM image are in the repository. If you object to their presence, the generators reproduce every one of them from a dump you make yourself.
