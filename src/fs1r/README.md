# src/fs1r: the hardware's values

What the FS1R itself holds or does, as numbers: read off the board, out of the EPROM, or measured. **No engine code lives here.** Presets, the engine, the tone generator and the DSP read these; nothing here reads them back.

| File | What | Status |
|---|---|---|
| `hardware.h` | sample rate, channel count, the filtered channels, the tick rate, level steps: the board's own numbers | KNOWN, never tuned |
| `tables.h` | the EPROM's conversion tables (note, velocity, EG, pan, send...) | generated by `tools/extract_tables.py`, do not hand-edit |
| `algorithms.h` | the 88-algorithm routing table | generated by `tools/extract_tables.py`, do not hand-edit |
| `rom_tables.h`, `.cpp` | the filter and effect hosts' EPROM tables (descriptors, LFO and coefficient tables) | generated by `tools/extract_vop3_rom.py`, do not hand-edit |
| `vop3_regs.h` | the DSP register map the hosts write | KNOWN |
| `cal.h` | every modelled constant, each naming the document that measured it | INFERRED: **the** file to edit when calibrating |

## Rules
- A value goes here only if the hardware has it. FSVR's own knobs go in `src/engine/tuning.h`.
- A disagreement with the unit means the value was read wrong, or for `cal.h`, is not yet calibrated.
